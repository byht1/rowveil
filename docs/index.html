postgres — QueryNest

Everything you need to work with data

No ORM, no project config. Point it at a database and start exploring.

Browse and edit

Fast grid with sorting, filters and paging. Edit cells, add and delete rows — changes are applied in one transaction.

Real SQL editor

Run one statement with ▶ or all of them, autocomplete for tables and columns, Prettify, Explain and VS Code shortcuts.

Readable JSON

JSON is detected even in plain text columns: formatted, highlighted and foldable. Big numbers and key order stay intact.

Schema management

Columns, constraints, indexes, views, enums, roles and RLS policies. Every change shows its SQL before you apply it.

Many databases, many windows

Save connections, switch between them, or open each database in its own window. Connect with fields or a URL.

Local and private

Your data never leaves your machine. The built-in engine listens on loopback only and answers only its own window.

See it in action

Dark by default, with eight themes including a light one.

postgres — QueryNest

Write SQL with highlighting and autocomplete. ▶ next to each statement runs just that one.

Feels like your code editor

The SQL console is built on CodeMirror 6 with the shortcuts you already know from VS Code.

  • Run the statement under the cursor, a selection, or everything
  • Context-aware autocomplete: tables, columns, aliases, functions
  • Prettify, Explain, history, multiple result sets
  • Export results to CSV or JSON with a native “Save as” dialog

Free and open source. Pick your system.

The installer shows where the program and your data are stored, and adds Start menu and “Open with” entries.

Installer (.msi) Portable .exe — no installation

macOS 11+

Universal app for Apple Silicon and Intel. Drag QueryNest to Applications.

Disk image (.dmg) Not notarized yet: right-click → Open the first time.

Linux

Debian / Ubuntu package with a desktop entry, or a portable archive. Needs WebKitGTK 4.1.

Package (.deb) Portable .tar.gz

Web server builds and checksums: all release files.

Get started in a minute

Pick the way that suits you.

Desktop app

Install it, or run the portable file. Open a SQLite file directly with “Open with → QueryNest”.

# or pass a database
querynest.exe C:\data\app.db
Downloads

Docker

The same UI in your browser — great for servers and teams.

docker build -t querynest .
docker run -p 4983:4983 \
  -e DATABASE_URL=postgres://… \
  querynest
Read the docs

From source

Needs stable Rust. Builds the desktop app and the web server.

git clone https://github.com/byht1/querynest
cd querynest
cargo build --release
